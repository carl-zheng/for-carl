# AppLovin Creative Workflow Skill

This package contains the production Skill currently used for AppLovin performance-ad video planning and KreadoAI production.

## Install

1. Download `applovin-creative-workflow.zip`.
2. Extract it into your Codex skills directory.
3. Keep the top-level folder name `applovin-creative-workflow`.
4. Restart or reload Codex skills.

The package includes the main `SKILL.md`, production references, KreadoAI character-library recovery rules, historical deduplication, voiceover standards, subtitle standards, QA gates, and the premium ASS subtitle template.

No API keys, product media, generated videos, or customer data are included.
